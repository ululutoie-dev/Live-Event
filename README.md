# ライブ告知ページ

## 管理画面(ブラウザから編集)のセットアップ
1. supabase.com で新しいプロジェクトを作る
2. SQL Editor に `supabase/schema.sql` を貼る。**先に `YOUR-ADMIN-EMAIL` を自分のメールに書き換え**てから Run
3. Authentication の Users から、そのメールでユーザーを追加(パスワードを設定し、メール確認済みにする)
4. Authentication の設定で、**新規サインアップ(Allow new users to sign up)をオフ**にする
5. Project Settings の API で、Project URL と `anon` `public` キーを控える(`service_role` キーは絶対に使わない)
6. Vercel のプロジェクトの Settings → Environment Variables に次の2つを追加し、再デプロイ
   - `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`
7. `公開URL/#/admin` を開いてログイン(管理画面だけはこの形です) → 編集 → 「保存して公開」

メモ
- 公開ページの一番下の小さな「編集」リンクからも入れます
- SNSに貼ったときのプレビュー(OGP)の仕組みは、下の「リンクプレビュー」を参照してください
- Supabaseの無料プロジェクトは、長期間アクセスがないと停止することがあります

## 複数イベントの使い方
- 管理画面(`公開URL/#/admin`)の最初の画面が「イベント管理」です。全イベントが開催日の新しい順に並びます
- 「＋ 新しいイベントを作成」で新規イベントを追加(既存のイベントには触れません)。新規は「非公開」で始まります
- イベント編集の「公開設定」で、イベントごとに公開/非公開を切り替え。非公開は管理画面にだけ残ります
- 公開ページ: 公開中が2件以上なら一覧(EVENTS)、1件ならそのイベントの詳細がトップに出ます
- 各イベントの個別URL: `公開URL/#/e/<公開URL用ID>`(管理画面の一覧の「告知ページ」から開けます。イベントのUUIDでも開けます)
- 出演者はイベントごとに独立しています。イベントを削除する機能はありません(非公開にして残す運用です)
- 短い公開URL: 編集画面の「公開URL用ID」(半角英小文字・数字・ハイフン、2〜40文字、例 `vol8`)を設定すると `公開URL/#/e/vol8` で開けます。IDは他のイベントと重複できません。`公開URL/#/event/<UUID>` の形も開けます
- 一覧の「QRコード」から、告知ページURLのQRコードを表示してPNG保存できます(URLは `公開URL/#/e/<公開URL用ID>`。ドメインは下の「公開ドメイン」を参照)
- Supabase側のSQL変更は不要です(既存のテーブル構成のまま動きます)

## リンクプレビュー(LINE・X・Facebookなど)
- `index.html` の固定のプレビュー(タイトル「LIVE EVENT」、説明、`public/ogp.jpg`)を、特定のイベント名・サンプルの情報を含まない汎用の内容にしてあります。`public/ogp.jpg` にも文字は入っていません
- **制約**: URLの `#` 以降は、ブラウザからサーバーに送られません。LINEなどのクローラーが受け取るのは、どのイベントでも `https://<ドメイン>/` だけです。そのため、`/#/e/<ID>` の形のURLのままでは、イベントごとのプレビューは出せません(どのイベントのURLでも、上の汎用プレビューになります)
- イベントごとのプレビューを出すには、URLに `#` を使わない形(例 `/e/<ID>`)にして、サーバー側(Vercelの関数)でプレビューを作る必要があります。現在のURL形式・QRコード・ルーティングを変える大きな変更になるため、このバージョンでは実装していません
- ブラウザで開いたときのタブの名前は、イベント名になります(これはReact側の処理です)

## 公開ドメイン
- 現在の本番ドメインは `https://live-event-red.vercel.app` です。`index.html` の `og:image` / `og:url` に、このドメインが書いてあります。ドメインを変えたら書き換えてください
- 管理画面のQRコードのURLは、管理画面を開いているドメインで作られます。固定したい場合は、Vercelの環境変数 `VITE_PUBLIC_URL`(例 `https://example.com`)を設定して再デプロイしてください

## Vercelへのデプロイ後に確認すること(未確認の項目です)
0. **Vercelが、更新したファイルを実際にビルドしているか**: Vercelの Settings → General → Root Directory が、`package.json` があるフォルダを指していること。別のフォルダが指定されていると、アップロードしても反映されません
1. `https://<ドメイン>/` のページのソース(Chromeで `view-source:`)に、`og:title` が「LIVE EVENT」、`og:image` が `…/ogp.jpg` と出ている(サンプルのイベント名が出ない)
2. `https://<ドメイン>/ogp.jpg` を開いて、画像が表示される
3. LINEの「Keepメモ」にイベントのURLを貼って、汎用のプレビューが出る。すでに貼ったURLは、LINE側のキャッシュで古い表示が残ることがあります。末尾に `?v=2` のように付けて試してください
4. 既存のイベントページ(`/#/e/<ID>`)・管理画面・QRコードがこれまでどおり動く

## 内容を変える
- `src/data.js` : イベント情報・出演バンド・メールアドレス・色とフォント(`theme`)
- 画像は `public/` に入れて `"/flyer.jpg"` のように指定(バンド写真は `public/images/`)
- `public/ogp.jpg` : SNSに貼ったときの既定のプレビュー画像(1200x630px、文字なし)。差し替える場合も、特定のイベント名は入れないでください

## Vercelで公開する
1. このフォルダをGitHubのリポジトリにアップロード
2. Vercelで「Add New → Project」からそのリポジトリを選び、そのまま Deploy(Viteは自動認識されます)
3. 公開ドメインが `live-event-red.vercel.app` 以外の場合は、`index.html` の `og:image` / `og:url` を書き換える(上の「公開ドメイン」を参照)
4. 公開URLをFacebook・X・ホームページ・メールに貼る(Instagramはプロフィールのリンク欄かストーリーズ)

## バンド・リンク・地図
- バンドを増やす: `src/data.js` の `bands` に `{ ... }` を追加(`youtubeUrl` と `links` は省略可)
- 外部リンク: `links: [{ label: "Instagram", url: "https://..." }]` をいくつでも
- 会場の地図: 会場名と住所からGoogleマップを開きます。別の地図にしたい場合は `mapUrl` にURLを入れる

## 色・フォントを試す
公開URLの末尾に `?design` を付けると「デザイン」ボタンが出ます。決まったら `src/data.js` の `theme` に反映。

## YouTube
動画は「公開」または「限定公開」にし、「埋め込みを許可」をオンにしてください。非公開だと誰も見られません。
